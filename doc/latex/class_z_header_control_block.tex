\doxysubsection{Detailed Description}
The \doxylink{class_z_header_control_block}{ZHeader\+Control\+Block} class contains the required information as a header for any ZRandom\+File This block is the first of the file\textquotesingle{}s header. It represents the signature of the file and contains the necessary set of addresses of all others header components. 

This is purely a file data block (while ZFile\+Descriptor owns file\textquotesingle{}s infradata in memory).

Nota Bene \+: file lock infos are positionned at the block beginning right after Start\+Sign to be quickly read/write accessed within file So, to access lock infos (Lock and Lock\+Owner), offset is \doxylink{zdatatype_8cpp_a2e3a005baae1ddce08bc66c4bbb72eab}{sizeof(uint32\+\_\+t)}
