\doxysubsection{Detailed Description}
\doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} physical layer is based on \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} physical layer. We may distinguish
\begin{DoxyItemize}
\item Main content file
\end{DoxyItemize}

This is based on a \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} base structure that embeds \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} infra-\/data extension.


\begin{DoxyItemize}
\item Indexes (ZIndex\+File)
\end{DoxyItemize}

Each defined index is stored and managed through its own \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} structure that embeds ZIndex\+File infra-\/data extension.

\begin{DoxyNote}{Note}
\doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} user does not have to care about this file structure, as he will address anything through \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}. However for some operations
\begin{DoxyItemize}
\item statistical data
\item split ZIndexes from \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}\textquotesingle{}s location it is good to known this architecture, as well as file\textquotesingle{}s naming conventions. 
\end{DoxyItemize}
\end{DoxyNote}
