This chapter is a user\textquotesingle{}s guide concerning the use of \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}.

In this example, we will
\begin{DoxyItemize}
\item load in a ZMF a mix of structured data and informal, varying length data with various format.
\item define two indexes
\item feed ZMF with data
\item remove records
\item search for data in multiple ways
\item use some ZMF utilities

\hypertarget{_z_m_f_quick_start_ZMFQSCreatIdx}{}\doxysection{\texorpdfstring{Creating Indexes}{Creating Indexes}}\label{_z_m_f_quick_start_ZMFQSCreatIdx}
At this stage, \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} structure is created including on storage, with all necessary infra-\/data to work with.

It\textquotesingle{}s time to create indexes.

For this example, we will create two indexes, among which one is "{}silly"{}, but necessary to show capabilities.

For creating an index the underneeth process is


\begin{DoxyItemize}
\item create a key dictionary CZDictionary \+: upload fields in their key order (key rank)
\item create the Index structure using this dictionary
\end{DoxyItemize}

This dictionary will store any field in the key order we define to interpret, extract, convert whenever necessary data.\hypertarget{_z_m_f_quick_start_ZMFQSCreatIdxFirst}{}\doxysubsection{\texorpdfstring{First index}{First index}}\label{_z_m_f_quick_start_ZMFQSCreatIdxFirst}
Its name will be "{}\+First Index"{}, with a touch of originality.


\begin{DoxyItemize}
\item String1 as first rank (an array of char)
\item Numeric\+Field as second rank (this is an array of float data type)
\end{DoxyItemize}

\begin{DoxyNote}{Note}
Index names must be at maximum 15 characters. 

I am conscious that the first field may be strictly enough. But, I want to show how we can manage multiple fields indexes.
\end{DoxyNote}
The process is \+:
\begin{DoxyItemize}
\item define fields in a key dictionary
\item control by printing fields definitions if you whish
\item create index within \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}
\end{DoxyItemize}

\doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} offers the possibility to define and use indexes\hypertarget{_z_m_f_quick_start_ZMFQSSearchTypes}{}\doxysubsection{\texorpdfstring{Index searches and free sequential searches}{Index searches and free sequential searches}}\label{_z_m_f_quick_start_ZMFQSSearchTypes}
\doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} allows the same free sequential search facilities than its base object \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File}. It is then possible to fully use these facilities.

Additionnally, \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} offers a search based upon index key values. Accessing key values using indexes saves drastically time and file accesses compared to free sequential search. However, there is an priority order between access types to respect \+:
\begin{DoxyItemize}
\item first access indexes and establish a collection
\item restrict collection using free sequential search (that will only scroll the existing collection content).
\end{DoxyItemize}

So that, there is a medium term to find between the capabilities of free sequential search and speed of access of indexed search.\hypertarget{_z_m_f_quick_start_ZMFQSIndexAccess}{}\doxysubsection{\texorpdfstring{Access ZMaster\+File using its indexes.}{Access ZMasterFile using its indexes.}}\label{_z_m_f_quick_start_ZMFQSIndexAccess}
It is possible to search for
\begin{DoxyItemize}
\item a single key value or for multiple key values i. e. a collection of values
\item using an exact key value or a partial key value
\end{DoxyItemize}\hypertarget{_z_m_f_quick_start_ZMFQSPartialKey}{}\doxysubsection{\texorpdfstring{Exact key value or partial key value in a search operation}{Exact key value or partial key value in a search operation}}\label{_z_m_f_quick_start_ZMFQSPartialKey}
A search may be made with a partial key value, this means that requested key size will represent a partial segment of index key. In this case, the search operation is made on the partial value of given key content and
\begin{DoxyItemize}
\item if a simple search operation is invoked, then the first found key value is returned
\item if a multiple search operation giving a collection of records ( either zsearch\+All or zsearch\+First, zsearch\+Next )
\end{DoxyItemize}\hypertarget{_z_m_f_quick_start_ZMFQSZKey}{}\doxysubsection{\texorpdfstring{Using ZKey object}{Using ZKey object}}\label{_z_m_f_quick_start_ZMFQSZKey}
ZKey is an object dedicated to index key search (see \doxylink{zdataconversion_8h_abca6a6e5a79bb4856b5a33f58812c899}{ZKey}). It allows to
\begin{DoxyItemize}
\item store index description (\doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} index number, Key dictionary)
