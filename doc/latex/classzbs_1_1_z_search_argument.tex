{\footnotesize\ttfamily \mbox{\hyperlink{zdataconversion_8h_abca6a6e5a79bb4856b5a33f58812c899}{bool}} ZSearch\+Argument\+::evaluate (\begin{DoxyParamCaption}\item[{ZData\+Buffer \&}]{p\+Record }\end{DoxyParamCaption})}



ZSSearch\+Argument\+::evaluate Evaluates all search condition matching a single give record p\+Record. 

Evaluation is made in the rule storage order (\doxylink{classzbs_1_1_z_array}{ZArray} rank order) from the first stored to the last stored rule.

For each condition argument \+:
\begin{DoxyItemize}
\item extracts field to evaluate from record
\item evaluates the conditions STRICTLY from (left to right) the first one to the last one.
\item AND / OR flag in the defined rule applies to the current member evaluation in regard to the actual result value at the moment of evaluation
\end{DoxyItemize}

Examples\+:


\begin{DoxyItemize}
\item true AND false OR true -\/\texorpdfstring{$>$}{>} (true AND false)= false OR true -\/\texorpdfstring{$>$}{>} TRUE
\item true OR true AND false -\/\texorpdfstring{$>$}{>} (true OR true)= true AND false -\/\texorpdfstring{$>$}{>} FALSE
\end{DoxyItemize}

\begin{DoxyNote}{Note}
if adhoc field definition points outside the varying record size, then condition is evaluated to false.
\end{DoxyNote}

\end{DoxyParams}
\begin{DoxyReturn}{Returns}

\end{DoxyReturn}
