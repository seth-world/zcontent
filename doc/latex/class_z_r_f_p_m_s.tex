\doxysubsection{Detailed Description}
The \doxylink{class_z_r_f_p_m_s}{ZRFPMS} class Performance monitoring system \+: collects data about read / write operations on content and header during a session. 

ZRandom\+File collects information about its activity. Data is stored within \doxylink{class_z_r_f_p_m_s}{ZRFPMS} class associated to ZFile\+Descriptor. This data has a life duration limitated to a session.

@\+Note a session starts from the ZRandom\+File\+::\+\_\+open method call until ZRandom\+File\+::\+\_\+close call \begin{DoxyVerb}It could be reported at any time using ZRandomFile performance reporting method.
\end{DoxyVerb}
