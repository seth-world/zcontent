\doxysubsection{Detailed Description}
The \doxylink{classzbs_1_1_z_console}{ZConsole} class. 

a second auxiliary server (ZSelect\+Server) referring to main ZSelect\+Server to which it relates.

This server accepts maximum 1 connection. It takes most of its parameters from the server to which it relates excepted \+:


\begin{DoxyItemize}
\item Port number \+: console port number \+: must be given in input
\item No user function \+: User function is core\+Console
\item Max\+Connection \+: 1
\item user\+Client\+Cancel\+Routine \+: Console cancel routine
\end{DoxyItemize}

Other parameters are directly taken from \textquotesingle{}father\textquotesingle{} server \+:


\begin{DoxyItemize}
\item p\+Family
\item ZAuth\+Method\+\_\+type
\item ZAuth\+\_\+\+Functor
\item Select\+Timeout
\item Non\+Blocking flag if any
\item p\+Read\+Timeout
\item p\+Write\+Timeout 
\end{DoxyItemize}
