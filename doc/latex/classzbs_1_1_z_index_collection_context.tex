\doxysubsection{Detailed Description}
The ZSIndex\+Collection\+Context class Maintain the context of a collection \+: 


\begin{DoxyItemize}
\item various type of searches and other operations
\item lock mask to be applied to records
\item last operation code
\item last operation status
\item compare size if search operation
\item comparison routine to use for key match (defaulted to ZKey\+Compare\+Binary)
\item Lowest key content to search (unique key content if simple search)
\item Highest key content to search (in case of searching for Interval values) 
\end{DoxyItemize}
