\doxysubsection{Detailed Description}
ZIndex\+File is the instance that manages one key for a \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} to which it relates. key definition is stored into a Key dictionary . It is a collection of ZIndex\+Field\+\_\+struct describing each field composing the key.

\begin{DoxyParagraph}{ZIndex\+File Key definition}
A key may be composed of several fields, possibly not contiguous, of \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} record. Key fields definition is stored in the dictionary that contains any single field definition of the elements composing the index key.
\end{DoxyParagraph}

Each field definition contains its data type and information about the way its value is extracted from \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} record.

\begin{DoxyParagraph}{What if a key field points out of a varying record boundaries ?}

\end{DoxyParagraph}
As \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} has a varying record size, from case to case, a field may point to outside the Master\+File record highest boundary. In this case, the field is taken (as if it has been extracted) as a binary zeroed field, whatever its data type could be. In case of signed numeric arithmetic data type, this means \textquotesingle{}negative zero\textquotesingle{} value, which is not a correct key data format (arithmetic zero is considered as positive).

\begin{DoxyParagraph}{Using keys with ZMaster\+Files}

\end{DoxyParagraph}
Any ZIndex\+File relates to a (father) \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} from which it gets its index data. A key structure must be defined using a Key dictionary and then will be populated transparently as soon as there will be an action done on \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} its relates to.

Key is used to search \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} content using a key value, total value or partial value.

Once it has been defined, it is necessary to registrate this key within \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}. This can be done using ZMaster\+File\+::\+Create\+ZIndex\+File method.
