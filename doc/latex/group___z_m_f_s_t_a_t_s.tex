\doxysubsection{Detailed Description}
The zstatistics struct This object is used to store statistic on performance during searches on Indexes for a \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}. 

\doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} embeds a set of Performance statistics facilities that gathers and extends the tools from \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File}.

The main objective is to
\begin{DoxyItemize}
\item follow activity on the different components of \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}
\begin{DoxyItemize}
\item \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} behavior
\item The behavior of each individual ZIndex\+File (one per defined index key)
\end{DoxyItemize}
\item monitor Performances on each of these above components with dynamic sessions You can then dynamically start a monitoring session and get the results when you wish so. These results will include a dynamic timer result with a delta time showing elapsed time since the session has been started.
\end{DoxyItemize}

\begin{DoxySeeAlso}{See also}
\doxylink{group___z_r_f_s_t_a_t_s}{Dump utilities and Statistical tools for ZRandom\+File}
\end{DoxySeeAlso}
Each high level operation (zsearch, zadd, etc...) gives its own zstatistics values, specific to the operation, whatever the result is, even in case of failure.

As it accesses \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File}, it collects also the whole \doxylink{class_z_r_f_p_m_s}{ZRFPMS} data set for the operation.
