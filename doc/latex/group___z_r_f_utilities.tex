\doxysubsection{Detailed Description}
\doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} embeds a set of utilities for managing disk space.\hypertarget{group___z_r_f_utilities_ZRFUtilClearing}{}\doxysubsubsection{\texorpdfstring{Clearing ZRF file content}{Clearing ZRF file content}}\label{group___z_r_f_utilities_ZRFUtilClearing}
If \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} contains records these records will be lost. If high\+Water\+Marking option has been selected and is on, the existing used file space will be marked to binary zero. File space remains allocated and is fully available as one free block with all available space to be used. see\+: \doxylink{group___z_r_f_utilities_gaf070af3c9e8f96d2490fede363ce5fb8}{ZRandom\+File\+::zclear\+File()}\hypertarget{group___z_r_f_utilities_ZRFUtilTrunc}{}\doxysubsubsection{\texorpdfstring{ZRF File truncation}{ZRF File truncation}}\label{group___z_r_f_utilities_ZRFUtilTrunc}
File content could be truncated to a physical size whenever possible. The remaining space at the end of the file (belonging to Free blocks pool) is truncated. If no free block are available and the physical end of the content file, nothing happens. Existing content remains unchanged. see\+: \doxylink{group___z_r_f_utilities_gacc8efce0bc83c4a42070fb249774c1aa}{ZRandom\+File\+::ztruncate\+File()}\hypertarget{group___z_r_f_utilities_ZRFUtilExtend}{}\doxysubsubsection{\texorpdfstring{ZRF File extend}{ZRF File extend}}\label{group___z_r_f_utilities_ZRFUtilExtend}
This utility artificially extend ZRF file space in adding a free block space at the physical end of the content file. see\+: \doxylink{group___z_r_f_utilities_gad670572a14bef4da4d6528f886a77b82}{ZRandom\+File\+::zextend\+File()}\hypertarget{group___z_r_f_utilities_ZRFUtilReorg}{}\doxysubsubsection{\texorpdfstring{ZRF File re-\/organization}{ZRF File re-organization}}\label{group___z_r_f_utilities_ZRFUtilReorg}
This utility has two goals
\begin{DoxyItemize}
\item reorder physically the file Records will be physically reordered in their respective logical rank. There will be no appearing change for users.
\item eliminate the possible holes between records At the end of the processing, the file\textquotesingle{}s content remains strictly unchanged, and records rank order is preserved. see\+: \doxylink{group___z_r_f_utilities_ga140af0f13d2364c1add73b52d957665a}{ZRandom\+File\+::zreorg\+File}
\end{DoxyItemize}\hypertarget{group___z_r_f_utilities_ZRFUtilClone}{}\doxysubsubsection{\texorpdfstring{ZRF File cloning}{ZRF File cloning}}\label{group___z_r_f_utilities_ZRFUtilClone}
This utility will duplicate the ZRF file. For doing this it will
\begin{DoxyItemize}
\item Create a new ZRF file with the same characteristics that the file to clone.
\item Populate this new file with origin content
\item Reorder physically the file in blocks\textquotesingle{} rank order
\item Add a free space at the end of the cloned file. see\+: \doxylink{group___z_r_f_utilities_ga551a53b83d383ebe136346a41b1902fa}{ZRandom\+File\+::zclone\+File()}
\end{DoxyItemize}\hypertarget{group___z_r_f_utilities_ZRFUtilHRebuild}{}\doxysubsubsection{\texorpdfstring{ZRF header rebuild}{ZRF header rebuild}}\label{group___z_r_f_utilities_ZRFUtilHRebuild}
This utility generates -\/ or re-\/generates -\/ a header context from a \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} well formed content file. This is usefull if a header file has been damaged or lost. see\+: \doxylink{group___z_r_f_utilities_ga4b3b04378233ab242f5d5d75ed0d8036}{ZRandom\+File\+::zheader\+Rebuild()}

\begin{DoxyNote}{Note}
this utility explores the file surface (surfacescan) of the file to detect start/end of blocks with a specific bytes marker. If ever there will be such a sequence in data, it will be detected as a start or end of block record and will induce a loss of data. 
\end{DoxyNote}

zclear\+File Clearing file content for the current opened \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} 

zclear will consider any block and user record within the \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} as deleted and unexisting anymore (even in the ZDeleted\+Block\+Pool).

For doing this, it will
\begin{DoxyItemize}
\item reset ZBlock\+Access\+Table pool (no more used blocks)
\item create one unique free block in ZFree\+Block\+Pool with a size corresponding to Size of the Content File -\/ size of a Block\+Header -\/ start of data
\item this block will be written as the first block of the content file (address start of data).
\end{DoxyItemize}

If highwater marking option has been selected, the freed space (size of free block as computed before) will be binary zeroed according highwater marking algorithm. \begin{DoxySeeAlso}{See also}
\doxylink{classzbs_1_1_z_random_file_a13d8aae675fd9e22417449e60715fbac}{ZRandom\+File\+::\+\_\+highwater\+Mark\+\_\+\+Block}
\end{DoxySeeAlso}
If \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} contains records these records will be lost. Current Logical address will be 0L, meaning start of the file. If high\+Water\+Marking option has been selected and is on, the existing used file space will be marked to binary zero. File space remains allocated and is fully available as one free block with all available space to be used.

File must be correctly setup (with appropriate path in various uri\+Strings ). If file is open then it will be closed before engaging the process. Once the process and been finished, will be re-\/opened for a later use with its previous open mode, if it was open, or left close if it was close while calling the method.

\begin{DoxyNote}{Note}
The whole file space remains allocated to \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} content file. If p\+Size mentions a value less than current file space, the file is not truncated and file space remains unchanged. if p\+Size is -\/1, then the existing space is kept. if p\+Size mentions a value greater than actual file space, then file is extended using posix\+\_\+fallocate and file size is adjusted to the given size.
\end{DoxyNote}
In order to reduce the amount of allocated disk space, it is required to use, after having used zclear\+File, \doxylink{group___z_r_f_utilities_gacc8efce0bc83c4a42070fb249774c1aa}{ZRandom\+File\+::ztruncate\+File}.
