\doxysection{what is a file session}
\hypertarget{group___z_r_f_session}{}\label{group___z_r_f_session}\index{what is a file session@{what is a file session}}
A file session for \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} and \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} starts when a file is opened and ends when a file is closed. Internal pointers and statistical counters and reset at the beginning of a session.
