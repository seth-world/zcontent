\doxysubsection{Detailed Description}
\doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} offers a set of tools allowing to maintain and recover its structure and its indexes.\hypertarget{group___z_m_f_utilities_ZMFUIndexes}{}\doxysubsubsection{\texorpdfstring{Managing Indexes}{Managing Indexes}}\label{group___z_m_f_utilities_ZMFUIndexes}

\begin{DoxyItemize}
\item zindex\+Rebuild Rebuilds an index for the current \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}. see ZMaster\+File\+::zindex\+Rebuild
\item z\+Repair\+Indexes A static method of \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} that allows to diagnose and repair damaged / missing indexes from the definition contained in \doxylink{classzbs_1_1_z_master_control_block}{ZMaster\+Control\+Block} of a given ZMasterfile. see ZMaster\+File\+::z\+Repair\+Indexes.
\item the whole set of XML routines that allows to store file parameters (Including Indexes definitions), and allows to rebuild / modify existing definition from the xml content. see 
\end{DoxyItemize}\hypertarget{group___z_m_f_utilities_ZMFUMaintenance}{}\doxysubsubsection{\texorpdfstring{ZMaster\+File maintenance}{ZMasterFile maintenance}}\label{group___z_m_f_utilities_ZMFUMaintenance}

\begin{DoxyItemize}
\item zreorg\+File

Reorganize main content file structure and recreates all indexes. Even if the purpose of this routine is the same than \doxylink{group___z_r_f_utilities_ga140af0f13d2364c1add73b52d957665a}{ZRandom\+File\+::zreorg\+File()}, the processing is much more important and takes care of all defined indexes that are rebuilded by this routine.
\begin{DoxyItemize}
\item content data file is reorganized \+: . blocks are physically ordered in rank order . holes are eliminated . free blocks are gathered into one unique free block at the end of the file . deleted blocks are physically removed from file
\item each index file is reordered to correspond to new addresses of content file, one after the other.
\end{DoxyItemize}
\end{DoxyItemize}

ZRaw\+Master\+File\+::zrepair\+Indexes Scans and Repairs indexes of a ZSMaster\+File. 

zrepair\+Indexes unlock the file in case it has been left open and locked.

For any defined index of the given ZSMaster\+File, it tests index file presence and controls ZIndex\+Control\+Block integrity.

It repairs damaged indexes if p\+Repair option is set to true (and rebuilds them).

It rebuilds all indexes if p\+Rebuild\+All is set to true

This routine may be used to test wether a file structure is still correct.

In addition, it may be used to regularly rebuild and reorder indexes if necessary.

\begin{DoxyWarning}{Warning}
Be sure to use zrepair\+Indexes in a standalone context, as it opens the file regardless the possible locks.
\end{DoxyWarning}
