Server connection and client authentication scheme

Server receive connection request from client

server creates a thread with argument \+: pointer to a structure containing
\begin{DoxyItemize}
\item a pointer to the ZSocket object
\item an authentication routine
\end{DoxyItemize}

Authentication routine reads from socket
\begin{DoxyItemize}
\item user name B64 coded
\item password B64 coded
\end{DoxyItemize}

Then call appropriate Authentication base routine (ZAuthentication\+\_\+base\+Linux) that check credentials and returns
\begin{DoxyItemize}
\item ZS\+\_\+\+SUCCESS if authentication is OK
\item error status with ZException set with appropriate message if not \+: either invalid username, invalid password or access right problem
\end{DoxyItemize}

Authentication routine then send returned status to client

If status is not ZS\+\_\+\+SUCCESS (not authenticated) connection is closed.
