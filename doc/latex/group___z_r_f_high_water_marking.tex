\doxysubsection{High\+Water\+Marking for ZRandom\+File surface}
\hypertarget{group___z_r_f_high_water_marking}{}\label{group___z_r_f_high_water_marking}\index{HighWaterMarking for ZRandomFile surface@{HighWaterMarking for ZRandomFile surface}}
High\+Water\+Marking is an option that consists in marking to binary zero any freed block (deleted record) in the file. This insure that deleted records are effectively and physically erased within the file. \begin{DoxyWarning}{Warning}
Chosing this option implies additional accesses to file surface while deleting a record. 

This option prohibit the possible recovery of deleted records 
\end{DoxyWarning}
