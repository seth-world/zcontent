\doxysection{File access information table (FAIT)}
\hypertarget{group___main_file_access}{}\label{group___main_file_access}\index{File access information table  (FAIT)@{File access information table  (FAIT)}}
This table registers the users / process id currently access the file.

This table is stored in File\+Header\textquotesingle{}s ZReserved zone (for a ZMF only main file is concerned by this table)

It mentions \+:


\begin{DoxyItemize}
\item username
\item process id
\item open date-\/time
\item open mode 
\end{DoxyItemize}
