\doxysubsection{Opening a file as an other file type than the native one}
\hypertarget{group___z_r_f_z_file__type}{}\label{group___z_r_f_z_file__type}\index{Opening a file as an other file type than the native one@{Opening a file as an other file type than the native one}}
\hypertarget{group___z_r_f_z_file__type_ZRFZFT}{}\doxysubsubsection{\texorpdfstring{Opening a file as an other file type than the native one}{Opening a file as an other file type than the native one}}\label{group___z_r_f_z_file__type_ZRFZFT}
There may be multiple reasons why we may want to open an existing file as another type than the native one it has been originally designed for \+:
\begin{DoxyItemize}
\item upgrade a \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} to a \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}
\item quick sequential search in an ZIndex\+File without opening its father \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File}
\item ...
\end{DoxyItemize}

However, doing such must comply to strict rules in order to preserve file\textquotesingle{}s integrity.

Two elements while define these possibility, and the returning status while openning files in such a way.\hypertarget{group___z_r_f_z_file__type_ZRFZFTCorr}{}\doxysubsubsubsection{\texorpdfstring{Correspondance between requested ZFile\+\_\+type and what we found in Header}{Correspondance between requested ZFile\_type and what we found in Header}}\label{group___z_r_f_z_file__type_ZRFZFTCorr}
\begin{DoxyVerb}*  File header         Requested       Actions
*  FileType            FileType
*
*  Any ZFile_type      ZFT_Nothing     no access   : rejected with   ZS_BADFILETYPE
*
*  ZFT_ZRandomFile     ZFT_ZRandomFile in any open mode.
*                      ZMasterFile     in this case, ZRandomFile will be upgraded to a ZMasterFile, and a ZS_FILETYPEWARN warning is issued.
*                                      The file must be open in exclusive access (ZRF_Exclusive) otherwise a ZS_BADFILETYPE will be emitted.
*
*
*  ZFT_ZMasterFile     ZFT_ZMasterFile in any open mode.
*                      ZFT_ZRandomFile only in ZRF_Read_Only open mode : in this case a ZS_FILETYPEWARN warning is issued
*                                      For other open modes, trying to open a ZMasterFile as a ZRandomFile will be rejected with a ZS_MODEINVALID
*
*  ZFT_ZIndexFile      ZFT_ZIndexFile  in any open mode.
*                      ZFT_ZRandomFile only in ZRF_Read_Only open mode : in this case a ZS_FILETYPEWARN warning is issued
*                                      For other open modes, trying to open a IndexFile as a ZRandomFile will be rejected with a ZS_MODEINVALI
* \end{DoxyVerb}


In case of error a status ZS\+\_\+\+BADFILETYPE is emitted and base \+\_\+open routine returns to caller without opening the file.

\begin{DoxyParagraph}{What is the logic underneeth \+:}

\begin{DoxyItemize}
\item Opening any file types as a \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} Because \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} manage and preserve ZReserved space without using infra-\/data, any other file type may be used as a read-\/only \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File}, even if it does not use ZReserved space. It only preserve it. To avoid changes in the file content it must be opened as read only.
\item Converting a \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} to \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} However, there is a utility (static \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} method) that allows to downgrade a \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} to a \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} \+: ZMaster\+File\+::zdowngrade\+ZMFto\+ZRF().
\begin{DoxyItemize}
\item destroys the Reserved block into file\textquotesingle{}s header
\item leave existing indexes to themselves
\end{DoxyItemize}
\item Opening a \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} as other type
\begin{DoxyItemize}
\item \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} cannot be openned as a \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} \+: it must be first converted to a \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} see ZMaster\+File\+::zupgrade\+ZRFto\+ZMF() static method. Using this method \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} will automatically create and write its \doxylink{classzbs_1_1_z_master_control_block}{ZMaster\+Control\+Block} into Reserved space. File must be opened as exclusive access (ZRF\+\_\+\+Exclusive\texorpdfstring{$\vert$}{|}\+ZRF\+\_\+\+All). \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} is created without any index.
\item this is not the case for ZIndexed\+File \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} is supposed to be a data file (and therefore not an Index file) and cannot not be upgraded to a ZIndex\+File. 
\end{DoxyItemize}
\end{DoxyItemize}
