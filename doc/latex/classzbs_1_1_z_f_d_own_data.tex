\doxysubsection{Detailed Description}
The \doxylink{classzbs_1_1_z_file_descriptor}{ZFile\+Descriptor} class \doxylink{classzbs_1_1_z_file_descriptor}{ZFile\+Descriptor} (further abbreviated ZFD) owns operational infradata IN PROCESS MEMORY to manage behavior of \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File}. 

\doxylink{classzbs_1_1_z_file_descriptor}{ZFile\+Descriptor} is a pure memory data structure used to manage File Header components. The components of \doxylink{classzbs_1_1_z_file_descriptor}{ZFile\+Descriptor} are synchronized with the header file content. \begin{DoxyNote}{Note}
when open exclusive mode (ZRF\+\_\+\+Exclusive) is made, then header file content is synchronized once at open time and again at close time.
\end{DoxyNote}
In non exclusivee mode, ZFD components are written in file header and updated as soon as an update operation occurs on file. It is preceeded with a Reserved block that is used by derived classes to store permanent infradata \+: \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} and ZIndex\+File uses this reserved space to store their own infradata structure.

As it is less susceptible to change than operational ZRF infradata, it is stored BEFORE \doxylink{classzbs_1_1_z_file_descriptor}{ZFile\+Descriptor} data itself, So that, ZRF header update will not induce rewrite on this portion of file.

Size of the reserved infradata area is set with Offset\+FCB field. \begin{DoxyVerb}     it is mostly composed of
\end{DoxyVerb}

\begin{DoxyItemize}
\item \doxylink{class_z_header_control_block}{ZHeader\+Control\+Block} \+: header for the file
\begin{DoxyItemize}
\item offset to Reserved
\item offset
\end{DoxyItemize}
\item \doxylink{class_z_file_control_block}{ZFile\+Control\+Block} \+: file\textquotesingle{}s operational infradata 
\end{DoxyItemize}
