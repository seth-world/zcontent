\doxysubsection{Detailed Description}
The ZSRFCollection class contains in its base class (ZArray$<$ssize\+\_\+t$>$)the resulting ranks set of a query operation on an \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File} or \doxylink{classzbs_1_1_z_master_file}{ZMaster\+File} thru various queries and specifically free search by field. 

This objects holds and manages
\begin{DoxyItemize}
\item the query resulting rows for relative \doxylink{classzbs_1_1_z_random_file}{ZRandom\+File}
\item the search rules
\begin{DoxyItemize}
\item adhoc field definition . field offset from beginning of record (start 0) \+: may be obtained with offsetof($<$struct$>$, $<$fieldname$>$), . field length in bytes \+: may be obtained with sizeof($<$field datatype$>$);
\item sequence of bytes to search as a ZData\+Buffer
\item query mask as a uint16\+\_\+t with values corresponding to \doxylink{group___z_r_f_free_search_gaf64b6cef70fbbf38fa4caa789b790656}{ZRFSearch\+\_\+type}
\item a flag (boolean) mentionning if the rule result must be ORed(true) or ANDed with the agglomerated boolean result.
\end{DoxyItemize}
\end{DoxyItemize}

\begin{DoxyNote}{Note}
there may be as much rules as required. But it is to be noticed that all rules are processed for any read record and a huge amount of rules may impact on global search performance. 
\end{DoxyNote}
