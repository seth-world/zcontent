\doxysubsection{Detailed Description}
The \doxylink{class_z_file_control_block}{ZFile\+Control\+Block} class contains all operational information of a ZRandom\+File. 

This block is written in header file.

It contains in particular the 3 block pools \+:
\begin{DoxyItemize}
\item ZBlock\+Access\+Table (ZBAT)\+: block pool that gives for a used block its address within the file using its rank number
\item ZFree\+Block\+Pool (ZFBT)\+: block pool of free/deleted blocks available for usage in record creation process
\begin{DoxyItemize}
\item ZHOT \+: block pool of holes deprecated \mbox{[}-\/ ZDeleted\+Block\+Pool (ZDBT)\+: pool of deleted block before they could have been grabbed by grab mechanism\mbox{]}
\end{DoxyItemize}
\end{DoxyItemize}
