Detailed Description

The ZSocketSelect class This socket class is created by the server when a ZBASE client connection is requested. This object uses ZBase protocol. Usage of this socket class is intended to be done within a ZThread thread. Each read operation is conditionned by a wait() putting the thread in dormant state, waiting a wakeup. Before any read operation, Thread event queue is scanned and events are processed. Then read operation occurs.
