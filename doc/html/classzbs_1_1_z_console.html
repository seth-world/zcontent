Detailed Description

The ZConsole class.

a second auxiliary server (ZSelectServer) referring to main ZSelectServer to which it relates.

This server accepts maximum 1 connection. It takes most of its parameters from the server to which it relates excepted :

  • Port number : console port number : must be given in input
  • No user function : User function is coreConsole
  • MaxConnection : 1
  • userClientCancelRoutine : Console cancel routine

Other parameters are directly taken from 'father' server :

  • pFamily
  • ZAuthMethod_type
  • ZAuth_Functor
  • SelectTimeout
  • NonBlocking flag if any
  • pReadTimeout
  • pWriteTimeout
