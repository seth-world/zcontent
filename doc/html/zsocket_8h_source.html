54 @note with debug you have to tell gdb to pass signal to running processes using instructions :
55
56handle SIGUSER1 pass nostop noprint
57handle SIGUSER2 pass nostop noprint
58handle SIGPIPE pass nostop noprint
59
60For Qt Creator, these instructions are set in menu <tools><options><gdb>
61then two windows
62<additional startup commands>
63or
64<additional attach commands> if you attach to a gdbserver
65
66 3 cases :
67 - SIGPIPE signal management (broken pipe):
68 signal must be inactivated using signal(SIGPIPE,SIG_IGN) instruction in the main Process (not in a Thread).
69 Broken pipe error is managed during read/write operations managed with status returned.
70
71 - 2 user chosen signals (beware the nature of the chosen signal) :
72 . for sending a signal to server saying the whole server must cancel or shutdown.
73 by default server cancelling signal is SIGUSR1 (user defined signal number 1)
74 . for sending a signal from server to client thread saying client thread must cancel or shutdown
75 by default client cancelling signal is SIGUSR2
