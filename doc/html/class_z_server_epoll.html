ZServerEpoll::run listen to incoming connections. accept connection, verify authentication, create a socket for incoming connection create a thread.

Parameters
pMaxConnectionsmaximum number of allowed connections. If negative, then accepted connection number is set to minimum value 1

Server connection and client authentication scheme

Server receive connection request from client

server creates a thread with argument : pointer to a structure containing

  • a pointer to the ZSocket object
  • an authentication routine

Authentication routine reads from socket

  • user name B64 coded
  • password B64 coded

Then call appropriate Authentication base routine (ZAuthentication_baseLinux) that check credentials and returns

  • ZS_SUCCESS if authentication is OK
  • error status with ZException set with appropriate message if not : either invalid username, invalid password or access right problem

Authentication routine then send returned status to client

If status is not ZS_SUCCESS (not authenticated) connection is closed.

Returns
