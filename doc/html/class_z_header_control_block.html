Detailed Description

The ZHeaderControlBlock class contains the required information as a header for any ZRandomFile This block is the first of the file's header. It represents the signature of the file and contains the necessary set of addresses of all others header components.

This is purely a file data block (while ZFileDescriptor owns file's infradata in memory).

Nota Bene : file lock infos are positionned at the block beginning right after StartSign to be quickly read/write accessed within file So, to access lock infos (Lock and LockOwner), offset is sizeof(uint32_t)
