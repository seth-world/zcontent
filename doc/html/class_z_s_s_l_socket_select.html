Detailed Description

The ZSSLSocketSelect class This socket is created and used by a SSLServerSelect to initiate and manage the SSL connection with a remote client endpoint Usage of this socket class is intended to be done within a ZThread thread. Each read operation is conditionned by a wait() putting the thread in dormant state, waiting a wakeup. Before any read operation, Thread event queue is scanned and events are processed. Then read operation occurs.
