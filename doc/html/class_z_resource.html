Detailed Description

The ZResource class Anything that could be searched for AND/OR locked is a ZResource and has a unique ZIdentity::id number. ZResource is characterized by Entity (Entity_type) application dependant code that refines what kind of resource is designated.

id and Entity are mandatory to fully define a ZResource.
