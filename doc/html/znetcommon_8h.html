typedef uint16_t ZProtocol_base

This file contains the network common content and authentication.

  • Authentication (used all access methods)
    • base authentication for windows USE_WINDOWS
    • base authentication for linux USE_LINUX
    • LDAP authentication requires OpenLDAP USE_LDAP
    • LDAP authentication for Active Directory requires MicroSoft Active Directory USE_LDAP and USE_WINDOWS
  • Network access detailed definitions
    • base access . thru base sockets (zremote/zbasenet/zsocket.h) . thru sslv5 sockets (zremote/zbasenet/zsslsocket.h) requires OpenSSL (must be installed by default)
    • RPC access (zremote/zrpc/zrpc.h)
    • CORBA access
    • WebService access (XML-RPC and not SOAP)
