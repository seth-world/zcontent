9/*
10 * Content : must hold the genuine record content
11 *
12 * KeyValue[0..n]->KeyContent Array that must hold the genuine key value (0 for primary key up to n )
13 *
14 *
15 * FieldPresence bitset is set by ZSMasterFile.
16 * Raw master file does not use FieldPresence :
17 * all fields are managed by application and therefore :
18 * - fieldPresence is set to nullptr
19 * - all fields are reputated to be present within record.
20 *
21 *
22 * This setup is done using :
23 * ZRawRecord::Content : this ZDataBuffer contains record data in universal format
24 *
25 * ZRawRecord::KeyValue [0..n] -> KeyContent : for each defined key, contains Key content as it will be written to index file.
26 *
27 * This routine returns a ZDataBuffer, ready to be written to main file, with the following structure :
28 *
29 * cst_ZBLOCKSTART (uint32_t) | Added by ZRandom Block routine :
30 * ZBID_Data 0x10 |
31 * ----------------
32 * |
33 * | ------------------------
34 * | FieldPresence (ZType_bitset) (bitset in URF format)
35 * | or
36 * | ZType_bitsetFull (uint32_t)
37 * | ------------------------
38 * | Record raw content size (uint64_t)
39 * | ------------------------
40 * | Record raw content (universal values (not URF))
41 * | -------------------------
42 * --------------
43 * uint32_t number of keys
44 * --------------
45 * Key 0 content
46 * key canonical size (uint32_t)
47 * key content (pure universal values (not URF) : values we can sort on )
48 * -------------
49 * Key 1 content
50 * -------------
51 * ...
52 * Key n content
53 * -------------
54 *
55 * cst_ZBLOCKEND (uint32_t)
56 *
57 */
