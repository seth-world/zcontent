Detailed Description

The fieldDesc_struct struct Field definition for ZMetaDic.

see ZIndexField_struct in <zindextype.h> see ZType_type

Nota Bene : As fields may have varying length, offet and lengths for each field are volatile data. It is available at ZRecord level within ZRecordDictionary.
