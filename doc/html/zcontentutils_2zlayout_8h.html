enum ZLayout_type : uint32_t

The ZLayout_type enum application dependant enum describing transactions capable of being source or destination of a drag and drop operation or a cut and paste operation for example with ZDataReference being used.

At the end of this file stays a set of value that is common to all applications and therefore should not be changed.
