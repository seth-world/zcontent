Detailed Description

template<class _ClientSocketType, class _ServerSocketType>
class zbs::ZServerSelectAbstract< _ClientSocketType, _ServerSocketType >

The ZServerSelectBase class template object with 2 sockets types :

  • _ServerSocketType : main object class that ZServerSelectBase is derived from. This class owns zlisten() and zaccept() methods Could be · ZServerSocket . ZSSLServerSocket
  • _ClientSocketType : base socket object class to be generated when a new client connection occurs (Not to be confused with ZClientSocket or ZSSLClientSocket : these classes manage the connection TO the server as a client) This class overloads zread() method to integrate wait() and event queue processing before reading the socket. Could be · ZSocketSelect . ZSSLSocketSelect

This template manage base connections and DOES NOT manage SSL.

To be used, it shall be derived to

  • ZServerSelect : creates a server for managing base clients connections
  • ZSSLServerSelect : creates a server for managing SSL clients connections (derived from ZSSLBase object)
