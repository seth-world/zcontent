ZClientSocket::clientConnect network connect over the client socket using ZBase protocol Send credentials for base Authentication. Protocol :

at each written block, server returns a ZNetException object content :

  • empty, with Status set to ZS_SUCCESS if successfull
  • with server ZExceptionBase content, in case of error.
    Parameters
    pUsername
    pPassword
    pCertificatepathname to a file containing a local copy of certificate. This certificate will be used to validate the one obtained from server. If equals nullptr (default value), then no server certificate validation is made.
    pFormata SSLFileFormat_type describing the format of the given pCertificate (if any). Defaulted to SFF_PEM (PEM format).
    Returns
